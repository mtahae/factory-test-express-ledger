Ledger API

A small expense tracking service. JSON in, JSON out.

Method Path Description
GET /health Liveness probe
GET /api/expenses List expenses. Optional from, to, category, vendor
GET /api/expenses/summary Totals overall and per category for a date range
GET /api/expenses/:id Fetch one expense
POST /api/expenses Create an expense
DELETE /api/expenses/:id Delete an expense
Data is held in memory and resets on restart.
